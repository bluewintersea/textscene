# TEXTSCENE

iPhone 클래식 잠금화면 문자 편집기. CALLSCENE의 색상, 폰트와 사진 크롭 방식을 이어받은 독립 정적 웹 앱입니다.

## 사용

이 폴더의 `index.html`을 열거나, 폴더 전체를 정적 호스팅에 올립니다. GitHub Pages에는 **모든 파일을 같은 위치에** 업로드하세요. 별도 설치나 빌드, API 키가 필요하지 않습니다. 로컬 파일로 열 때는 GIF가 기본 처리 방식으로 동작하며, 웹 서버에서는 작업 스레드로 처리됩니다.

- 문자 1~4개, 발신인 및 내용 직접 입력. 입력 순서대로 도착하며 최신 문자가 위에 표시됩니다.
- 사진 업로드, 고정 9:19.5 크롭, 드래그·휠·두 손가락·확대 슬라이더·방향키 지원. 취소하면 기존 사진과 크롭을 유지합니다.
- 전체 이미지에는 별도의 백그라운드 사진을 업로드합니다. 1:1 크롭, 드래그·휠·두 손가락·확대 슬라이더·방향키와 어둡게 조절을 지원하며 휴대폰 배경과 독립적으로 관리됩니다.
- 백그라운드 그라데이션: 색상 선택, 길이 0~100%, 방향 4종, 켜기/끄기. 선택한 색에서 투명으로 이어지는 그라데이션이 바깥 배경에 적용됩니다.
- 미리보기에서 휴대폰 화면/전체 이미지를 전환할 수 있으며 두 모드 모두 클릭하여 문자 도착 효과를 재생합니다.
- 시간은 숫자로 입력하면 자동으로 HH:MM으로 정리됩니다(1234 → 12:34, 941 → 09:41). 날짜는 달력에서 선택하며 요일과 한글/영문 표기가 자동 반영됩니다.
- 문자마다 수신 시간을 입력할 수 있습니다(09:30, 5분 전 등). 공란이면 화면 언어에 따라 지금/now로 표시됩니다.
- 상태바 표시 전환, 한글/영문 알림 표시. 상단바 요소는 기존 위치보다 양쪽에서 5px씩 안쪽에 배치됩니다.
- 알림 박스 불투명도와 배경 블러를 별도로 조절합니다.
- 화면 또는 재생 버튼 클릭으로 도착 애니메이션을 재생합니다.
- 화면 PNG: 모든 알림이 표시된 1080×2340 정지 이미지.
- 전체 PNG: 1200×1200 정사각형. 백그라운드와 그라데이션 위 오른쪽에 휴대폰 테두리와 화면을 배치합니다. 휴대폰은 기존 중심 위치를 유지하며 축소 전 크기의 95%로 표시됩니다. 사진을 선택하지 않으면 기본 단색 배경을 사용합니다.
- 화면 GIF: 540×1170 / 720×1560 / 1080×2340, 20fps 도착 모션, 마지막 화면 1.8초 유지, 무한 반복.
- 전체 GIF: 1200×1200 정사각형으로 고정 저장합니다. 화면 GIF 크기 선택과 독립적입니다. 바깥 사진·그라데이션은 고정되고 휴대폰 안에서 문자가 도착합니다. GIF는 최대 256색으로 저장됩니다.
- GIF 용량 최적화: 첫 장면은 전체를 저장하고 이후에는 이전 장면과 달라진 영역만 저장합니다. 색상표를 공유하며 해상도·색상·프레임 수·재생 시간은 유지합니다. 화면 GIF와 전체 GIF에 모두 적용됩니다.
- GIF 색상 부드럽게: 항상 적용. 원본의 색조를 기준으로 밝기를 섞어 색상 경계를 줄입니다. 어두운 배경에 아이콘의 초록색이 점처럼 섞이는 현상을 방지하도록 보정했습니다. 저장 시간과 파일 크기가 늘어날 수 있습니다. GIF의 최대 256색 제한으로 원본 색상을 완전히 보존하지는 못합니다.
- 긴 내용은 최대 4줄로 줄임 표시됩니다. 발신인은 한 줄입니다.
- 사진과 문자는 서버로 전송하지 않습니다. 문자·시간·날짜·각종 설정·이미지 원본·크롭 위치를 이 브라우저에 자동 저장하며, 같은 사이트를 다시 열거나 새로고침하면 복원합니다. 이미지는 IndexedDB, 문자와 설정은 localStorage에 보관합니다. 브라우저의 사이트 데이터를 지우면 저장 내용도 삭제됩니다.

## 포함 파일

`index.html`, `styles.css`, `app.js`, `draft.js`, `gif-worker.js`, `gif-utils.js`, `gifenc.js`, 두 개의 `.woff2` 폰트, `gifenc-LICENSE.md`, `.nojekyll`, 이 문서를 함께 유지하세요.

GIF 인코더: [gifenc 1.0.3](https://github.com/mattdesl/gifenc), MIT 라이선스. `gifenc.js`는 배포된 CommonJS 파일을 브라우저와 Worker에서 사용하도록 감쌌으며, 변경 영역 저장을 위해 프레임의 좌측·상단 위치 지정을 추가했습니다. 폰트는 기존 CALLSCENE 프로젝트의 사용자 제공 Apple SD Gothic Neo 파일을 사용합니다.
