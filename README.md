# TEXTSCENE

iPhone 클래식 잠금화면 문자 편집기. CALLSCENE의 색상, 폰트와 사진 크롭 방식을 이어받은 독립 정적 웹 앱입니다.

## 사용

이 폴더의 `index.html`을 열거나, 폴더 전체를 정적 호스팅에 올립니다. GitHub Pages에는 **모든 파일을 같은 위치에** 업로드하세요. 별도 설치나 빌드, API 키가 필요하지 않습니다. 로컬 파일로 열 때는 GIF가 기본 처리 방식으로 동작하며, 웹 서버에서는 작업 스레드로 처리됩니다.

- 문자 1~4개, 발신인 및 내용 직접 입력. 입력 순서대로 도착하며 최신 문자가 위에 표시됩니다.
- 사진 업로드, 고정 9:19.5 크롭, 드래그·휠·두 손가락·확대 슬라이더·방향키 지원. 취소하면 기존 사진과 크롭을 유지합니다.
- 시간, 날짜, 상태바, 한글/영문 알림 표시.
- 알림 박스 불투명도와 배경 블러를 별도로 조절합니다.
- 화면 또는 재생 버튼 클릭으로 도착 애니메이션을 재생합니다.
- 화면 PNG: 모든 알림이 표시된 1080×2340 정지 이미지.
- 전체 PNG: CALLSCENE과 같은 검은 휴대폰 테두리와 측면 버튼을 포함한 1180×2440 이미지. 휴대폰 바깥은 투명합니다.
- 화면 GIF: 540×1170 / 720×1560 / 1080×2340, 20fps 도착 모션, 마지막 화면 1.8초 유지, 무한 반복.
- 전체 GIF: 선택한 화면 크기에 비례하여 테두리를 추가한 590×1220 / 787×1627 / 1180×2440 이미지. 모든 프레임에서 휴대폰 바깥은 투명합니다. GIF는 최대 256색 및 1비트 투명도를 사용합니다.
- 긴 내용은 최대 4줄로 줄임 표시됩니다. 발신인은 한 줄입니다.
- 사진과 문자는 서버로 전송하지 않습니다. 새로고침하면 초기 상태로 돌아갑니다.

## 포함 파일

`index.html`, `styles.css`, `app.js`, `gif-worker.js`, `gif-utils.js`, `gifenc.js`, 두 개의 `.woff2` 폰트, `gifenc-LICENSE.md`, `.nojekyll`, 이 문서를 함께 유지하세요.

GIF 인코더: [gifenc 1.0.3](https://github.com/mattdesl/gifenc), MIT 라이선스. `gifenc.js`는 배포된 CommonJS 파일을 브라우저와 Worker에서 사용하도록 감쌌습니다. 폰트는 기존 CALLSCENE 프로젝트의 사용자 제공 Apple SD Gothic Neo 파일을 사용합니다.
